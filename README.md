# 💰 DreamPaisa

> Your simple, smart, and personal finance companion.

DreamPaisa is a personal finance management web application designed to help users track their income, expenses, budgets, and financial habits in one place.

## ✨ Features

- 📊 **Dashboard** – Get a quick overview of your financial health.
- 💸 **Expense Tracking** – Record and categorize daily expenses.
- 💰 **Income Tracking** – Keep track of your income sources.
- 🗂️ **Categories** – Organize transactions using customizable categories.
- 📅 **Financial Overview** – Understand your spending patterns over time.
- 🔐 **Authentication** – Secure user authentication and account management.
- 📱 **Responsive Design** – Works across desktop and mobile devices.
- 🌙 **Dark & Light Mode** – Comfortable experience in any environment.
